Signlight for Jira

Support

Need help installing Signlight or understanding an issue status? Send a concise description and, if useful, a screenshot to Reware Apps support.

Quick start

  1. Ask a Jira administrator to install Signlight.
  2. Open the Jira issue whose content should be acknowledged.
  3. Find Signlight issue sign-off in the issue context.
  4. Open the panel and select Sign issue.

What the colors mean

  • Red: no active sign-off exists.
  • Green: the active sign-off matches the current summary, description and attachment set.
  • Yellow: relevant issue content changed after signing.

Common questions

Which changes turn the status yellow?

Changes to the summary, description or attachment set. Comments, status changes and routine field updates do not invalidate the sign-off.

Who can revoke a signature?

Only the Atlassian account that created the active signature.

Does Signlight store issue content?

No. It stores a fingerprint derived from relevant content, plus the issue ID, account ID and timestamps. It does not copy the summary, description or attachment files into app storage.

Is this a legal electronic signature?

No. Signlight is a lightweight internal acknowledgement tool. It is not designed for regulated or legally binding e-signatures.
